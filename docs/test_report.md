Известные ограничения (честно для отчёта)
Style adherence низкая (0.26–0.40 в среднем). Причина: 80 имён в train.
Цель ТЗ (≥85%) достижима при 2000+ имён на стиль. См. docs/scorers_report.md.

Style leakage в LSTM. Имена похожи между стилями. Причина та же —
мало данных. С ростом датасета исправится.

Human eval — демонстрационный. Нужно заполнить реальными оценками.

C-4 (путь экспорта) — не реализован. Файлы всегда в data/.
